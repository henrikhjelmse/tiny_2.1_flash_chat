TINY 2.1 Back to chat

API Guide

The API is available at the same address and port as the web app. Send questions to POST /ask; the answer is streamed back as plain text.

Ask a question

POST /ask

Send JSON with the question in q. You can also set creativity (0-9, default 5). Questions are limited to 72 printable ASCII characters, and the model responds in English.

curl -N -X POST http://localhost:5014/ask ^
  -H "Content-Type: application/json" ^
  -d "{\"q\":\"what is the capital of peru\",\"creativity\":5}"

JavaScript (Fetch)

const response = await fetch("/ask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ q: "what is 7 times 8", creativity: 0 })
});

const answer = await response.text();
console.log(answer);

PHP (cURL)

<?php
$ch = curl_init("http://localhost:5014/ask");
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => ["Content-Type: application/json"],
    CURLOPT_POSTFIELDS => json_encode([
        "q" => "what is 7 times 8",
        "creativity" => 0
    ]),
    CURLOPT_RETURNTRANSFER => true
]);

$answer = curl_exec($ch);
if ($answer === false) {
    throw new RuntimeException(curl_error($ch));
}
curl_close($ch);
echo $answer;

The response uses the MIME type text/plain; charset=utf-8. It is sent as the model generates text, so clients can read the response body as a stream to display the answer immediately.

Get model information

GET /info

Returns the model dimensions as JSON:

curl http://localhost:5014/info
{
  "D": 96,
  "layers": 4,
  "heads": 4,
  "hidden": 256
}

The returned values depend on the loaded TINY.BIN model.

Tips

  • Start the app with python app.py. The default port is 5014.
  • Use python app.py --port 8000 to choose a different port.
  • creativity: 0 selects the most likely next character; higher values add more variation.
  • The model generates answers one character at a time and has a limited context length.
